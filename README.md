<h1 align="center">Taskbeat</h1>

<p align="center">
  Музыкальный плеер для Windows с «островом» на панели задач.<br>
  VK Музыка, YouTube, SoundCloud, Яндекс Музыка и пульт Spotify — в одном окне.
</p>

---

## Что умеет

**Остров на панели задач**
- Тонкая полоска над панелью задач. При наведении она раскрывается в карточку с обложкой, перемоткой и кнопками.
- Пилюля с текущим треком и живым эквалайзером, анимация «полоска ↔ остров».
- Уведомления Windows выезжают из полоски. Стандартные всплывающие окна при этом можно скрыть: в центре уведомлений всё остаётся.
- Напоминания, погода (Open-Meteo), часы, «Скопировано», зарядка.
- Два монитора:
  - полоска есть на каждом мониторе, остров раскрывается на том, где навели курсор;
  - если на основном мониторе игра или видео на весь экран, остров переезжает на второй.
- Масштаб под 2K/4K. Двойной клик по раскрытому острову открывает плеер.

**Плеер**
- VK Музыка:
  - моя музыка, рекомендации, плейлисты, поиск;
  - микс по треку, «Играть следующим», добавление в плейлисты, скачивание;
  - «Не нравится».
- Синхронные тексты песен (VK и LrcLib).
- Кроссфейд, таймер сна, 10-полосный эквалайзер с пресетами.
- YouTube (с картинкой-в-картинке), SoundCloud, Яндекс Музыка — встроенными вкладками.
- Пульт для Spotify и любого другого плеера Windows.
- Глобальные горячие клавиши: каждую можно переназначить или выключить. Если сочетание обычно занято Windows, плеер предупредит.
- «Отзыв или баг» — текст и скриншот прямо из приложения уходят мне в тг (через посредник, см. [relay](relay/README.md)).

**Два режима**
- **Классический** — плавные анимации и красивые эффекты.
- **Игровой** — минимум нагрузки: без анимаций, режим эффективности Windows, низкий приоритет. Что именно отключать, выбирается в настройках.

## Установка

1. Скачайте `Taskbeat-<версия>-win-x64.zip` со страницы [Releases](../../releases).
2. Распакуйте в любую папку и запустите `Taskbeat.exe`.

Нужна Windows 10 (2004+) или Windows 11, x64. Нужен Microsoft Edge WebView2 Runtime — в Windows 11 он уже установлен. Отдельно ставить .NET не нужно: всё уже внутри.

## О входе в VK

> [!WARNING]
> У VK нет открытого API для музыки. Поэтому Taskbeat входит так же, как сторонние мобильные клиенты: по QR-коду, по логину и паролю или через страницу VK как запасной вариант. Это **неофициальный способ**: VK может в любой момент его отключить, а для аккаунта есть риск ограничений. Используйте на свой страх и риск.

Пароль нигде не сохраняется. На компьютере хранится только ключ доступа, зашифрованный средствами Windows (DPAPI).

## Данные и приватность

- Taskbeat не собирает статистику и ничего не отправляет разработчику.
- Настройки и ключ VK лежат в `%APPDATA%\Taskbeat`, профиль встроенного браузера — в `%LOCALAPPDATA%\Taskbeat`.
- Запросы уходят только в сервисы, которыми вы пользуетесь, а также в Open-Meteo (погода) и LrcLib (тексты).

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bat
build.cmd
```

Готовый самодостаточный exe появится в папке `dist`.

Структура проекта:

| Папка | Что внутри |
|---|---|
| `app/Core` | плеер, звуковой движок, VK, тексты, настройки, горячие клавиши |
| `app/Hub` | окно плеера: страницы, меню, эквалайзер, тексты |
| `app/Island` | остров на панели задач, мониторы, уведомления |
| `relay` | посредник Cloudflare Worker: отзывы → Telegram |
